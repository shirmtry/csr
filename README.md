Here is how you can locate and format your **Task 1** submission URL for the `README.md` file:

### **URL Format for Submission**

Your submission URL should point directly to the `README.md` file in your public GitHub repository. It will typically look like this:

```text
https://github.com/<your-github-username>/<your-repository-name>/blob/main/README.md

```

### **Quick Checklist before Submitting:**

1. **Public Repository:** Make sure your repository settings on GitHub are set to **Public** so the instructor or automated grader can access it.
2. **File Existence:** Ensure a file named exactly `README.md` exists in the root directory of your repository.
3. **Content Verification:** Confirm that your `README.md` includes the project name and details about the simple interest calculator.

Once you have verified your repository is public and copied the correct URL from your browser's address bar while viewing the `README.md` file, paste it directly into the submission box for Task 1.
